# Aswin SK Portfolio — Design Direction

## Ground-truth reference
The site should retain the reference portfolio’s polished single-page rhythm: a compact sticky navigation, an availability signal, a strong hero headline, clear primary and secondary actions, social links, a technology section, project work, experience, education, CV access, and a concise contact close. The implementation is original to Aswin SK and uses a blue editorial identity instead of copying source code or branding.

## Chosen direction

### Design Movement
Contemporary Swiss editorial design fused with technical interface notation: disciplined typography, generous whitespace, and precise blue annotation details.

### Core Principles
- Lead with confident, readable typography and a deliberately asymmetric composition.
- Use blue as a functional signal system: cobalt for action, ink for focus, sky for context, and paper white for breathing room.
- Make technical credibility visible through metadata, tags, small labels, and concise project narratives.
- Prefer quiet depth, crisp borders, and tactile texture over generic gradients or excessive rounded cards.

### Color Philosophy
The palette moves from deep ink navy to paper white so Aswin’s work feels both dependable and inventive. Cobalt blue is the ownable signal color: it marks momentum, links, hover states, and the moments where the visitor should act. Pale sky blue carries secondary context without competing with the content.

### Layout Paradigm
A long-form editorial canvas with a left-side section index on large screens and offset content columns. The hero uses a split composition: message and actions on the left, portrait and availability note on the right. Project cards alternate alignment so the page feels curated rather than assembled from a centered grid.

### Signature Elements
- A cobalt square monogram mark and thin ruled annotation lines.
- Small uppercase labels with slash prefixes, like `/ selected work` and `/ current focus`.
- Blue data dots and compact metadata strips that make each project feel like a case-file entry.

### Interaction Philosophy
Interactions should feel immediate and intentional. Navigation anchors scroll cleanly, buttons lift by a few pixels, project links reveal directional arrows, and cards respond with a subtle blue edge rather than a noisy effect.

### Animation
Use 180–260ms transform/opacity transitions for buttons, cards, and navigation. The hero portrait enters with a restrained slide and opacity reveal; project rows stagger by 50ms. Respect `prefers-reduced-motion` by removing entrance movement while keeping focus and hover clarity.

### Typography System
Use Space Grotesk for display headlines and IBM Plex Mono for labels, project metadata, and utility text. Headings use tight tracking and responsive clamp sizing; body copy stays at a comfortable 1.65 line height. Avoid all-caps for long copy.

### Brand Essence
Aswin SK is a remote-ready full-stack developer who turns practical ideas into thoughtful, interactive web products. Personality: precise, inventive, dependable.

### Brand Voice
Headlines are direct and quietly ambitious. CTAs are specific and active, never generic filler.

Example lines:
- “Interfaces that make complex work feel clear.”
- “Open a project file →”

### Wordmark & Logo
The mark is an abstract interlocking A/S symbol built from two cobalt strokes. The text wordmark stays typographic and understated so the symbol carries recognition at small sizes.

### Signature Brand Color
Cobalt Signal — `#2563EB`.
